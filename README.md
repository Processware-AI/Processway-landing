# Processware Landing

Processware는 표준, 산업 규제, 직무별 업무 방식을 AI가 실행 가능한 프로세스 자산으로 바꾸고, 조직이 이를 구독하거나 구매해 바로 운영할 수 있게 해주는 표준 프로세스 구독 플랫폼입니다.

이 저장소는 Processware 서비스 정의와 GitHub Pages용 랜딩 페이지를 담고 있습니다.

## 서비스 한 문장 정의

표준 문서를 바로 쓰는 프로세스로 바꾸고, 실행 기록과 심사 증적까지 자연스럽게 쌓아주는 AI 표준 프로세스 플랫폼.

## 핵심 가치

- 표준 문서를 실제 업무 프로세스로 변환
- 정책서, 절차서, 지침서, 템플릿, 기록, 매핑표 구성
- 실행할 때마다 증적과 기록 생성
- 심사, KPI, NCR, GAP 분석 지원
- 프로세스 개정과 개선 루프 연결
- 표준별, 산업별, 직무별 프로세스팩을 구독 또는 구매 가능

## 기본 산출물 체계

| 코드 | 유형 | 역할 |
|---|---|---|
| POL | 정책서 | 원칙, 방침, 책임 |
| PRO | 절차서 | 업무 흐름과 관리 절차 |
| WI | 업무지침서 | 실무 수행 상세 |

| REF | 참고자료 | 외부 표준, 법규, 가이드 요약 |

## 플랫폼 운영 흐름

| 단계 | 의미 | 주요 기능 |
|---|---|---|
| Plan | 표준 프로세스 수립 | 표준 분석, 프로세스 설계, 문서 생성 |
| Do | 프로세스 실행 | WI 실행, 승인, 반려, 기록 생성 |
| Check | 심사와 점검 | 증적 대조, KPI, NCR, GAP 분석 |
| Act | 제·개정 | 원인분석, 개정 큐, 개선안 생성 |

## 포지셔닝

Processware는 표준 문서 자동 생성기가 아니라, 표준 프로세스를 구독하고 실행하는 운영 플랫폼입니다.

> 표준 프로세스, 이제 처음부터 만들지 마세요. 필요한 프로세스팩을 구독하고, 우리 조직에 맞게 실행하세요.
